How we check

We show what each service says on its own public status page. Nothing is estimated.

1. Live from your browser

Each status page fetches the service's public Statuspage API (for example discordstatus.com/api/v2/status.json) when you open it or press Check now.

2. Snapshot every 15 minutes

A scheduled GitHub Action saves the same official JSON to data/status.json, so the last known status shows even if the live fetch fails. Each entry keeps its real fetch time.

3. Fixes from official docs

Device fixes come from Apple Support and Google Play Help, with a source link on each step.

What we never do

  • Show estimated or placeholder report counts. We do not collect user reports.
  • Back fill outage history before tracking began.
